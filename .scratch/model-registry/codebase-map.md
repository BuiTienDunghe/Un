## 2. Hard constraints

**Invariants**

1. **#1 Postgres is truth; Qdrant/BM25 derived** (DEVELOPMENT_PLAN.md:34). An embedding version is bound to the contents of two Qdrant collections whose model identity Qdrant does not store (qdrant_store.py:58-65 payload has no model field). Switching = rebuild from Postgres (rebuild_qdrant.py:1 docstring). Postgres must record which version produced which vectors; `document_versions.embedding_model` (postgres/models.py:99) is the existing, unwritten slot.
2. **#2 No DB transaction around a model call** (:35). Registry read once at process start into memory; never consulted inside a session (postgres_document_service.py:580-607 and chunk_context_service.py:97-104 are session-free by design).
3. **#3 Additive migrations with downgrade** (:36) — any new table/column.
4. **#4 RAG-quality change becomes default only after the eval gate** (:37). RAG-quality roles = general (index-time annotations), embedding, reranker. Promotion must cite a passed gate: D1 multidoc (evaluate_rag.py, baseline data/evaluation/rag_multidoc_baseline.json), heldout (training/common/eval_heldout.py), MTEB (data/evaluation/mteb/*/summary.json). Candidate measured on the lab stack (eval_stack.py:36-66 ports 8100/8200/8300, own DB + collection; nightly_eval.py:43-45).
5. **#5 One-click launcher always boots on a clean machine** (:38). Today honoured by the launcher's .env pin before uvicorn (run-local-ai-core.bat:62-72), keyed on import only, and by `from_config(enabled_override=...)` (reranker_service.py:37-67). Nothing in lifespan catches exceptions (main.py:51-231). A registry load loop must end in a state that starts, never start a network download, and be bounded by `OLLAMA_HEALTH_TIMEOUT_SECONDS` (settings.py:136).
6. **#6 Autonomous actions auditable and revocable** (:39). A fallback is autonomous: durable log event (LoggingService sink after main.py:84; idiom `logger.bind(event=..., source=...)` at reranker_service.py:53-61, main.py:188-189), an `ATTENTION_*` marker read by check_operational_alerts.py:56-57, one-step revert.
7. **#7 Fixed inference budget; Ollama serves one request at a time; scoring models must have a measured latency threshold** (:40). No warm generation call at boot; no second in-process model loaded alongside the active one; a fallback general tag is a second 9b-class download plus residency, not free (data/vram_budget.md:25-30).
8. **#8 Measure before schema change** (:41). Fill existing unwritten columns first; a new `(version_id, embedding_version)` table only after a measured need.
